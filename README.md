
# GreenScape Landscaping Website

A modern, responsive landscaping business website built using HTML5 and CSS3.

## Features

- Responsive layout for desktop, tablet, and mobile
- Navigation with a mobile menu
- Landscaping service cards
- Project gallery
- Business introduction and benefits
- Contact form interface
- Nature-inspired color palette
- Responsive CSS media queries

## Technologies Used

- HTML5
- CSS3
- Google Chrome / modern web browser

## How to Run Locally

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in a browser.

For live previews, use the Live Server extension in VS Code.

## Project Purpose

This project demonstrates front-end web development skills and
serves as a customizable demo website for landscaping businesses.

## Disclaimer

This is a portfolio demonstration. Business details, images,
and sample content should be verified or replaced before
the website is used by a real business.
